
Gestor de Agenda C++ 

Sistema de  gestion de contactos con listas, pila, cola y arbol binario de busqueda.
Permite agregar, buscar, ordenar, eliminar y mostrar contactos.

Caracteristicas 

Agregar, listar y eliminar contactos.
Búsqueda secuencial y binaria.
Historial de acciones (pila).
Contactos pendientes (cola).
Árbol BST para ordenamientos Inorden y Preorden.

Requisitos técnicos
Lenguaje: C++
